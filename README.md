# 个人金融系统 · 学生财务 & 创业资金管理

基于需求文档《学生财务 & 创业管理系统 - 完整设计方案 V2.0》打造的专业级单页应用。

## 启动方式
- 已通过本地 HTTP 服务预览：http://127.0.0.1:8765/index.html
- 或双击 `index.html` 直接用浏览器打开（推荐 Chrome / Edge）
- 演示账号：`demo` / `demo123`（首次登录自动预置演示数据）

## 已实现功能（12 大模块）
1. 登录/注册 — 离线模式，本地存储，数据不上传
2. 总控面板 — 总资产/总负债/净资产/今日速览/预算进度/最近交易
3. 智能记账 — 文字 + 语音（Web Speech API）智能解析，自动识别金额/账户/分类/对方/地点
4. 交易记录 — 银行级全路径追溯，筛选/搜索/导出 CSV
5. 账户管理 — 多账户联动（银行卡/支付宝/微信/现金/创业储备金/负债），余额自动同步
6. 预算管理 — 月度总预算 + 分类预算，超支预警进度条
7. 月度复盘 — 收支趋势/收入构成/支出排行/环比/自力更生指数/创业小结
8. 教育投资 — 按时间轴 + 按地点查看求学花费
9. 创业看板 — 利润独立核算、利润趋势、成本结构、利润率
10. 负债管理 — 花呗/信用卡/贷款，还款提醒，净资产计算含负债
11. 资金流向 — 桑基图可视化（来源→账户→去向）
12. 通知中心 — 预算预警/大额提醒/还款提醒/系统通知

## 技术栈
- 纯前端 SPA，零构建步骤
- HTML5 + CSS3（金融暗色主题，可切换浅色）
- 原生 JS（模块化架构）
- Chart.js 图表
- localStorage 本地持久化（可导出/导入 JSON 备份）
